Sea Glass 是一套以磨砂玻璃质感为特征的界面设计系统：低饱和度的柔和色块、全圆角的胶囊形控件、表面颗粒噪点和向下偏移的柔和投影。所有可点击的控件都是浮在浅色背景上的独立色块，靠颜色和投影与背景区分，不使用描边。

## 原则

- **一个控件，一块颜色。** 每个控件只使用一个色调的四个颜色：`*-fill` 作底色，`*-hi` 作选中或内嵌高亮，`*-glow` 作底部高光，`*-ink` 作文字和图标。不在同一控件内混用两个色调。
- **全圆角。** 按钮、导航栏、输入栏和圆形按钮都使用 `radius-pill`；只有卡片和面板使用 `radius-lg`，菜单和弹层使用 `radius-md`。
- **浮起，而非描边。** 控件与背景的区分来自 `shadow-float` 投影。不要给控件加边框。
- **留白充足。** 控件之间至少 `space-4`，区块之间 `space-8`。一屏内的色块数量控制在 3 到 5 个。

## 文案

- 界面文字使用句首大写（Sentence case）：“New collection”，不写 “New Collection”。中文界面不加句号。
- 按钮标签以动词开头，两到三个词：“Manage storage”“添加照片”。
- 输入栏的占位文字是一句直接的提问提示，例如 “Ask anything”“搜索照片”。
- 状态标签用一到两个词：“Online”“Pending”“已完成”。
- 不使用表情符号，不使用感叹号。

## 颜色

- 页面背景使用 `paper`，浮起的面板和弹层使用 `surface`。正文用 `ink`，次要文字用 `ink-muted`。
- 七个色调，每个色调有 `-fill`、`-hi`、`-glow`、`-ink` 四个 token：
  - `cobalt`：主要操作、输入栏。每个视图只有一个 `cobalt` 主要按钮。
  - `lilac`：导航栏、分段切换、创作类入口。
  - `seafoam`：完成、在线、成功。
  - `amber`：警告、待处理。
  - `coral`：账户头像圆标；作为状态时只表示失败或危险操作。
  - `aqua`：信息提示、共享状态。
  - `frost`：默认控件、次要操作、普通卡片。
- 色块上的文字一律使用同色调的 `*-ink`，不使用白色或 `ink`。两套主题中 `*-ink` 在 `*-fill` 与 `*-hi` 上的对比度均不低于 5.2:1。
- `*-fill` 与 `paper` 的对比度约为 1.2 到 1.8:1，不足以单独识别控件边界；控件通过投影、文字或图标识别，因此不能用空白的无文字色块作为按钮。
- 状态不能只靠颜色区分：`seafoam`、`amber`、`coral` 状态必须附带文字或图标。
- 主题有 Day（默认）与 Night 两套。Night 主题中色块变为深色、`*-ink` 变为浅色，组件代码不需要区分主题。

## 字体

- 字体族 `sans`：Google Sans Flex（可变字体，OFL 开源许可，字重 400–700、光学尺寸 6–144），中文回退到 PingFang SC、Noto Sans SC、Microsoft YaHei。从 Google Fonts 加载：`https://fonts.googleapis.com/css2?family=Google+Sans+Flex:opsz,wght@6..144,400..700&display=swap`。
- 字号层级：`display`（56/60，600）页面大标题，每页至多一处；`title`（28/34，600）区块标题；`heading`（20/26，600）卡片标题；`body`（16/24，400）正文；`label`（17/22，500，字距 -0.02em）胶囊控件内的文字，分段导航用 15px；`caption`（13/18，500）标签和辅助说明。
- 控件内文字统一用 `label`，字重 500，不用粗体。

## 间距与尺寸

- 间距阶梯：`space-1` 4、`space-2` 8、`space-3` 12、`space-4` 16、`space-6` 24、`space-8` 32、`space-12` 48、`space-16` 64（单位 px）。
- 控件高度：标准按钮与圆形按钮 `space-12`（48px）；分段导航 48px（选项 38px）；输入栏 `space-16`（64px）；小号按钮与小号圆形按钮 36px；Chip 28px。
- 胶囊色块内嵌元素到外沿的距离：SegmentedNav 为 5px，PromptBar 为 `space-2`。
- 卡片内边距 `space-4`；卡片头部的图标按钮用 36px 的小号尺寸。

## 质感：光从上方照下的磨砂色块

色块按“光从正上方照在一块半透明磨砂玻璃上”的物理效果绘制：光从顶面进入，在体内散射，从底部和两端透出，并在色块正下方留下一条带色的透射光，再往下是灰色投影。

- 底色：不透明的 `*-fill`。
- 顶部：上沿一道 2px 的暗边（`*-ink` 6%，用渐变绘制），其下是一道很淡的亮带，在 10% 高度处最亮，到 30% 高度消失。参考图的上沿紧接底色并略暗，没有亮边。
- 中部：一条横贯全宽的较深色带（玻璃在中部更厚），中心在 48% 高度，颜色为 `*-fill` 混入 16% `*-ink`（在 oklch 中混合，保持色度）；色带内另有两处更深的斑块，中心分别位于 24–44% 与 56–76% 宽度处的随机位置（每个色块各不相同），因此明暗左右不对称。Fab 的色带更集中、更深（参考图中 Fab 中部比顶部暗约 8%）。各项数值见“可调参数”。
- 下部：从 62% 高度开始向下逐渐提亮，到底边达到 `*-glow`，覆盖下方约三分之一。
- 边缘高光沿轮廓内侧分布（直边和圆角都贴合轮廓）：一圈较淡的 `*-glow` 柔光环绕整个轮廓；底部另有一条更宽的 `*-glow` 高光带，沿两端圆弧向上延伸并逐渐变窄。高光带宽度由 `--sg-rim` 控制，约为控件高度的四分之一：48px 控件 12px，36px 控件 9px，64px 输入栏、大号按钮和卡片 16px，96px 圆形按钮 22px。
- 底边：底边本身最亮（与参考图一致），紧贴底边的一线只有很轻的回落。`*-glow` 比 `*-fill` 更亮，色相略有偏移（丁香紫偏粉，钴蓝偏青）。
- 色块正下方：先是一段带色的透射光（`*-fill` 60% 混入 `shade`），再往下是 `drop` 颜色的灰色同形投影。两者都按 `--sg-rim`（即控件高度）缩放：投影向下偏移 `--sg-rim` 的 0.85 倍，约为控件高度的 0.21 倍（48px 控件约 10px，66px 导航栏约 14px，与参考图一致），模糊为 `--sg-rim` 的 0.15 倍，下边缘较清晰；`xl` 按钮偏移 1.2 倍（72px 高时约 23px）。卡片保持较小的 `shadow-float`。嵌在面板内的控件、Chip 使用较小的同类效果和 `shadow-rest`。
- 表面颗粒：随机排布的细小碎片。`components/bundle.js` 在加载时用带种子的随机数生成器（mulberry32，种子每次加载随机）按设备像素绘制两块 200px 的图块：一块记录全部碎片的位置和强度（用作遮罩），一块只记录亮碎片（白色）。碎片为 3 或 4 个角的细长多边形，随机旋转，0.2–2.5px 大小。暗碎片的颜色取该色调的 `*-ink`，因此在珊瑚色上偏棕红、在水蓝色上偏蓝灰；亮碎片为白色。每 100 平方像素约 10 个暗碎片、5 个亮碎片，覆盖率和对比度按参考图测量。碎片之间的表面保持平滑。颗粒层向下延伸到色块下方的透射光区域（约 `--sg-rim` 的 0.7 倍），在那里逐渐消失；卡片和 Chip 不延伸。深色主题中暗碎片改用 `*-fill` 的深色（`*-ink` 在深色主题中是浅色），中部色带也改为向黑色加深；亮碎片减弱到约三分之一；切换主题时图块自动重新生成。每个色块出现时再取一个随机偏移 `--sg-grain-pos`，相邻色块的颗粒不会对齐。性能相关的处理见“性能”一节。没有 canvas 时退回 `components/bundle.css` 中的 SVG 噪点（中性色，不延伸）。强度由 `opacity-grain` 控制，默认 0.3，可调范围 0–0.4，0 为无颗粒；颗粒层实际不透明度为该值的 1.5 倍（碎片很小，需要更高的不透明度才能显出）。
- 调整颗粒强度：在任意元素上覆盖 CSS 变量，该元素及其内部所有色块都会改变。全局调整写在 `:root`：

  ```css
  :root { --opacity-grain: 0.3; }           /* 全局 */
  .settings-panel { --opacity-grain: 0; }   /* 局部关闭 */
  ```

  React 中也可以写在 `style` 上：`<div style={{ '--opacity-grain': 0.15 }}>`。
- 导航选中项使用半透明的 `*-hi`（50%），能透出导航栏的底色和颗粒（参考图为 `#c8dcfa` 叠在 `#a7bffb` 上）；Chip 的选中底色和按钮的悬停底色仍为 `*-hi` 实色混合。边缘 5px 柔化，不加投影。
- 色块内的圆形按钮（IconButton `inset`）使用 `*-fill` 与 `*-hi` 各半的颜色，上下两端略亮，边缘 5px 柔化。
- 渐变只使用该色调自身的颜色，不跨色调。
- 固定在内容之上的顶栏和底部栏可另加 `backdrop-filter: blur(var(--blur-glass))`，此时底色改为 `*-fill` 的 90% 不透明度。

## 可调参数

玻璃质感的各项效果都由 CSS 自定义属性控制，默认值写在 `components/bundle.css` 的 `:root` 中。写在 `:root` 上作用于整页；写在任意元素上作用于该元素及其内部的所有色块；写在某个组件的类名上只改变该组件。颗粒参数（`--sg-fleck-*`）作用于整页，因为颗粒图块全页共用。组件页的“参数”一节可以逐项拖动调整，并导出对应的 CSS。

| 分组 | 属性 | 默认值 | 作用 |
| --- | --- | --- | --- |
| 颗粒 | `--opacity-grain` | 0.3 | 颗粒层强度（token） |
| 颗粒 | `--sg-fleck-dark` / `--sg-fleck-light` | 10 / 5 | 每 100 平方像素的暗、亮碎片数 |
| 颗粒 | `--sg-fleck-size` | 1 | 碎片大小倍数 |
| 颗粒 | `--sg-fleck-stretch` | 1 | 碎片细长程度倍数，小于 1 更圆 |
| 颗粒 | `--sg-fleck-dark-alpha` / `--sg-fleck-light-alpha` | 1 / 1 | 暗、亮碎片的强度倍数 |
| 颗粒 | `--sg-grain-reach` | 0.7 | 颗粒向下延伸到透射光区域的距离，`--sg-rim` 的倍数，0 为不延伸 |
| 中部色带 | `--sg-band-y` | 48% | 色带中心距顶部的位置 |
| 中部色带 | `--sg-band-spread` | 24% | 色带半高 |
| 中部色带 | `--sg-band-strength` | 38% | 色带不透明度 |
| 中部色带 | `--sg-band-depth` | 16% | 色带颜色中 `*-ink` 的占比（在 oklch 中混合，保持色度） |
| 中部色带 | `--sg-spot-strength` / `--sg-spot-width` | 40% / 32% | 两处随机位置深色斑块的不透明度与半宽；强度为 0 时左右对称 |
| 高光 | `--sg-glow-start` | 62% | 底部高光的起点 |
| 高光 | `--sg-glow-mid` | 50% | 底部高光在 84% 高度处的不透明度；底边始终为完整的 `*-glow` |
| 高光 | `--sg-edge-glow` | 85% | 沿轮廓内侧的边缘光不透明度 |
| 高光 | `--sg-highlight-width` | 1 | 底部高光带和边缘光的宽度倍数 |
| 高光 | `--sg-top-light` / `--sg-top-line` | 20% / 6% | 顶部亮带不透明度、顶部暗线中 `*-ink` 的占比 |
| 投影 | `--sg-shadow-y` / `--sg-shadow-blur` | 0.85 / 0.15 | 灰色投影的偏移与模糊，`--sg-rim` 的倍数 |
| 投影 | `--sg-cast-light` | 60% | 透射光中 `*-fill` 的占比，其余为 `shade` |
| 组件倍数 | `--sg-band-gain` / `--sg-band-depth-gain` / `--sg-glow-shift` | 1 / 1 / 0% | 组件相对整页设置的倍数和偏移。Fab 使用 1.55 / 1.5 / 8%，使中部色带更集中、更深 |

示例：

```css
:root { --sg-band-strength: 50%; --sg-shadow-y: 1; }   /* 整页 */
.settings-panel { --sg-band-strength: 0%; }          /* 该区域内的色块不显示中部色带 */
.sg-fab { --sg-band-gain: 2; }                        /* 只改 Fab */
```

脚本中可使用 `SeaGlass.setParams({ bandStrength: 50, fleckDark: 14 }, element?)`（数字自动加单位，`null` 取消覆盖）、`SeaGlass.getParams(element?)`、`SeaGlass.resetParams(element?)`；`SeaGlass.params` 列出全部参数的 CSS 名称、默认值和建议范围。修改颗粒参数后图块在停止拖动约 0.1 秒后重新生成。

## 性能

- 边缘高光（底部高光带与沿轮廓的边缘光）用遮罩绘制：`components/bundle.js` 由圆角矩形的有向距离和高斯衰减算出与原内阴影相同的明暗，生成只含形状、不含颜色的遮罩，玻璃的 `::after` 透过它涂 `*-glow`。支持 `-webkit-mask-box-image` 的浏览器使用九宫格遮罩：圆角加 2px 中段，拉伸到任意尺寸，同一圆角和高光参数的所有表面共用一张；遮罩在 ResizeObserver 回调中同步生成（每张不到 1 毫秒），首帧即为遮罩。其他浏览器按尺寸在 Worker 中生成整张遮罩，就绪前使用内阴影。主题切换不需要重新生成遮罩。
- 跟随鼠标的光点画在表面自身的第一层背景上；`--sg-mx`、`--sg-my` 注册为不继承，鼠标移动只改变表面自身的样式，颗粒层、高光层和内部元素都不重绘。
- 鼠标经过或按下的表面（以及离开后 0.7 秒内），表面本身和它的颗粒层、高光层各自单独合成，悬停颜色、光点和按压只重绘表面背景。其余时间不占用额外显存。
- 顶部暗线和底部细线用一层渐变绘制，不用内阴影。
- 颗粒图块在 Worker 中用 OffscreenCanvas 绘制（CPU 画布），异步编码为 PNG，以 `blob:` 地址交给 CSS，按主题和参数缓存；不允许 Worker 时在主线程的下一帧绘制。
- 深浅色判断读取 `data-theme` 和系统设置，颗粒参数读取根元素的行内值；变化时不读取计算样式，避免整页同步重算。
- 主题切换的两帧内暂停所有过渡动画。按压形变期间元素以 `transform` 合成，不重绘。
- 长页面可以给区块加 `content-visibility: auto`。它会裁掉区块外的绘制，因此区块需留出投影的空间（组件页用上下 32px、左右 16px 的内边距并以同样的负外边距抵消，再加 `overflow-clip-margin`）；区块内有打开的菜单时改回 `visible`。

## 交互状态

- 悬停光：所有色块（`.sg-glass`）以及导航选项、无底色圆形按钮，悬停时出现一团跟随鼠标的 `*-hi` 柔光（半径 46px，卡片 90px），0.3 秒淡入、淡出；按钮类控件的底色同时向 `*-hi` 提亮 30%。只在支持悬停的设备上生效。
- 按下光：按下时柔光以按下点为中心扩大到 90px（卡片 160px）并变亮，松开后收缩、淡出。
- 按下形变（果冻质感）：所有色块以及导航选项、无底色圆形按钮在按下时沿“中心→按下点”的实际方向形变，任意角度都适用。沿该方向压缩（按在边缘时约 7px，越靠近中心越弱），垂直方向略微鼓起以保持面积；对侧边缘为变换原点，因此被按的一侧向内凹、对侧不动。按在中心时为整体向内的均匀压缩（约 3px）。形变用二维矩阵 R(θ)·diag(1−a, 1+b)·R(−θ) 实现，圆形在各方向的形变幅度一致。按住拖动时方向平滑转向指针。松开后由弹簧回弹：先越过原形向外鼓，再往复几次衰减到静止，约 0.6 秒。形变量有上限，小控件不会过度变形。键盘 Enter/空格按下时从中心形变；输入框内打字不触发。系统开启“减少动态效果”时不形变。
- 通用规则：上述悬停光、按下光、按下形变由 `components/bundle.js` 中的共享监听统一处理，组件无需单独实现。自定义元素加类名 `sg-spot`（光效）、`sg-jelly`（形变）即可获得相同效果；加 `sg-nojelly` 可关闭某个色块的形变。
- 选中：内嵌的半透明 `*-hi` 高亮胶囊（SegmentedNav，边缘柔化，无投影）或 `*-hi` 底色（Chip）。
- 禁用：整体不透明度 `opacity-disabled`，保留文字，鼠标指针为 not-allowed。
- 焦点：不使用深色描边。控件边缘一圈 2px 细环，颜色为该色调的中间色（`*-ink` 58% 混入 `*-fill`，在 `paper` 上不低于 3:1），外侧再扩散一圈同色调柔光（`*-fill` 70%），约 0.3 秒淡入。输入栏获得焦点时按“光从上方照下”处理：顶部不显示细环，原有的顶部暗线也隐去；细环只出现在两侧（约 1px）和底部（约 2.5px），沿两端圆弧自然消失；柔光保留，底色向 `*-hi` 提亮 20%。按钮等控件只在键盘聚焦（`:focus-visible`）时显示。

## 图标

- 线条图标，24 × 24 网格，1.9px 线宽，圆头圆角，无填充。React 中使用 `SeaGlass.Icon`，颜色跟随 `currentColor`；需要 `<img>` 时使用 `assets/Icons/` 中的 SVG 文件。
- 图标与文字间距 `space-2` 到 `space-3`。导航栏中只有选中项显示图标。
- 不使用表情符号作为图标。
- 本系统没有标志文件；需要品牌标识时以 Google Sans Flex 600 字重排出名称 “Sea Glass”。

## 组件

组件在 `components/bundle.js` 中，以 `window.SeaGlass` 暴露，页面需先加载 React 18 与 ReactDOM 18，再加载 `tokens.css` 与 `components/bundle.css`。

- `Button`：操作按钮；`xl` 尺寸的纯图标宽胶囊用于挂断等单一大面积操作。
- `IconButton`：圆形图标按钮、账户圆标。
- `SegmentedNav`：同级视图切换的胶囊导航栏。
- `PromptBar`：带附件、语音输入与语音对话入口的输入栏。
- `Chip`：状态与筛选标签。
- `GlassCard`：磨砂卡片。
- `Meter`：带标签和数值的用量条。
- `Sparkline`：无坐标轴的小型折线图。
- `Slider`：在连续范围内选择数值的滑块。
- `Toolbar`：玻璃胶囊里的一组图标操作按钮；“更多”按钮打开竖向菜单，所有按钮移动到竖向列表中并显示文字。
- `Fab`：最主要操作的悬浮按钮，大圆角方形，可带文字。
- `SwatchPicker`：任意颜色的圆形色块单选器。
- `ToggleButton`：带下方标签的图标切换按钮；关闭时为平面胶囊，开启时变为玻璃圆角方形。传入 `menuItems` 时作为“更多”菜单按钮，菜单从按钮处展开。
- `ScrollArea`：带 Sea Glass 滚动条的可滚动区域；任意元素加类名 `sg-scroll` 也可使用该滚动条样式。
- `Icon`：线条图标，部分图标有实心版本（`filled`）。

## 示例页

- `DashboardExample`：总览页，演示侧边导航、汇总栏、数据卡片和错误卡片的组合方式。数据卡片用 `frost` 色调；卡片内的主指标用彩色 Chip 加大号数字，下方为 Sparkline，次级指标用 Meter；加载或同步失败时，卡片内嵌 `surface` 底色的错误框，包含 `coral` 的“Failed”标签和错误说明。

# Meter

带标签和数值的水平用量条，用于存储空间、配额、进度等百分比指标。

- 使用方提供：`value`（0–100）；可选 `label`、`icon`、`tone`（默认 `cobalt`）、`valueText`（替换默认的 `xx.x%`）、`warnAt`（默认 80）、`dangerAt`（默认 90）。
- 轨道使用 `*-fill`，进度使用 `*-ink`，两者对比度不低于 5.2:1。
- 数值达到 `warnAt` 时色调自动改为 `amber`，达到 `dangerAt` 时改为 `coral`。数值文字始终显示，状态不只靠颜色表达。
- 同一指标在同一页面内始终使用同一色调；不同指标并列时使用不同色调。
- 轨道高度 8px，标签与数值使用 15/20、字重 500，数值用等宽数字。

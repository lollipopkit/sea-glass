# ToggleButton

带下方文字标签的图标切换按钮，用于通话控制、播放控制等一排并列的开关。

- 使用方提供：`icon`、`label`（显示在按钮下方，同时作为无障碍名称）；受控时传 `pressed` 与 `onChange`，非受控时可传 `defaultPressed`。可选 `tone`（默认 `aqua`）、`size`（`sm` / `md`）、`filled`（默认实心图标）。
- `toggle={false}` 时不切换、不带 `aria-pressed`，用作同一排中的普通按钮，配合 `onClick`。
- 传入 `menuItems`（`{ icon?, label, onClick?, disabled? }[]`）时成为菜单按钮，用于“更多”：点击后不切换，按钮在菜单打开期间显示为开启状态，一个玻璃菜单从按钮处展开。菜单出现在空间较大的一侧（按钮上方，或标签下方），与按钮左缘或右缘对齐；展开时从与按钮重合的方框放大到菜单尺寸，各项从按钮中心依次滑出（约 0.44 秒，末尾有轻微回弹），收起时按相反路径缩回按钮（约 0.3 秒）。可选 `menuLabel`（菜单名称，默认用 `label`）、`menuTone`（默认 `frost`）。
- 菜单键盘操作：上下方向键、Home/End 移动焦点；Esc 或点击菜单外关闭，焦点回到按钮；选择一项后执行其操作并关闭；用键盘打开时焦点进入第一项。
- 关闭状态：88 × 68px 的平面胶囊，填充 `surface` 混入 4% `cobalt-fill`（日间约 `#fafbff`，参考图为 `#fafafe`），没有颗粒、高光和投影，图标为 `ink`。
- 开启状态：变为该色调的玻璃圆角方形，圆角 16px（约为高度的 22%，按参考图测量），带颗粒、边缘高光、投影和按压形变。圆角、颜色、高光和颗粒在 0.35–0.45 秒内一起过渡。
- 标签 16/20、字重 500，颜色为 `ink-muted` 78% 混入中性灰（日间约 `#626a6e`，参考图 `#626970`），在底板上对比度 4.62:1。同一排按钮间距 `space-2`，整排放在比 `surface` 深的底板上（参考图为浅蓝灰底板），否则关闭状态的胶囊与背景无法区分。
- 小号 `sm`：64 × 48px，开启圆角 12px，标签 13/16。

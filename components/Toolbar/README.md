# Toolbar

一组图标操作按钮，排在一个玻璃胶囊里。

- 使用方提供：`items`（`{ icon, label, onClick?, disabled?, more? }`，`label` 为必填的无障碍名称和悬停提示）、`aria-label`；可选 `menuItems`（只在菜单中出现的操作，格式同 `items`）、`tone`（默认 `lilac`）、`filled`（默认使用实心图标）、`closeLabel`（菜单打开时“更多”按钮的名称，默认 `Close`）、`menuLabel`。
- 高 60px（与 Fab 等高），按钮为 48px 无底色圆形按钮，图标 24px。实心图标：`share`、`comment`、`edit`、`image`；其他图标沿用线条样式。
- 键盘：整个工具栏只占一个 Tab 位置，左右方向键、Home/End 在按钮之间移动焦点。
- 3 到 6 个操作为宜，更多的操作放进 `menuItems`，由最后的“更多”按钮打开。“更多”按钮是带 `more: true` 的项，或没有 `onClick` 的 `more-vert` 项。
- 菜单：点击“更多”后，工具栏胶囊展开为竖向的玻璃面板（宽至少 232px，圆角 24px）。工具栏中的每个按钮从横排位置移动到竖向列表中的位置并显示文字（按顺序错开 22ms），`menuItems` 从“更多”按钮的位置展开到分隔线下方，“更多”图标旋转变为关闭图标。约 0.46 秒完成，末尾有轻微回弹。关闭时按相反路径收回（约 0.34 秒）。
- 面板向空间较大的一侧展开（下方不足 320px 且上方更多时向上），靠近右边缘时右对齐；展开期间工具栏原来的位置保持不变，面板浮在内容之上。
- 菜单打开后：上下方向键、Home/End 在各项之间移动焦点；Esc 或点击面板外关闭，焦点回到“更多”按钮；选择任一项后执行其操作并关闭。用键盘打开时焦点进入第一项。系统开启“减少动态效果”时直接切换。
- 常与一个 `Fab` 并排放置，两者等高。

# SwatchPicker

从一组颜色中选一个的圆形色块选择器。

- 使用方提供：`options`（`{ id, color, label }`，`color` 为任意 CSS 颜色，`label` 为颜色名称）、`aria-label`；受控时传 `value` 与 `onChange`，非受控时可传 `defaultValue`；可选 `size`（`md` 48px / `lg` 96px）。
- 每个色块只用给定的一个颜色推导出玻璃质感：底色为该颜色；高光 `hi` 为该颜色与白色混合；底部高光 `glow` 偏向暖白；勾选符号和选中环为该颜色与深色混合。因此任意颜色都有与色调色块一致的质感。
- 选中项显示勾选符号，外侧一圈与页面背景隔开的细环。
- 键盘：作为单选组只占一个 Tab 位置，方向键切换并直接选中。
- 颜色名称写在 `label` 里，读屏软件读出；不要只靠颜色区分选项含义。

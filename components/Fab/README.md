# Fab

页面上最主要操作的悬浮按钮，形状为大圆角方形。

- 使用方提供：只有图标时传 `label`（无障碍名称）；传入 `children` 时成为扩展形态，显示图标加文字。可选 `icon`（默认 `plus`）、`tone`（默认：方形 `coral`，扩展形态 `aqua`）、`size`（`md` / `lg`）、`filled`（实心图标）。
- 尺寸：方形 60px、圆角 17px（约为边长的 28%，按参考图测量）；大号 96px、圆角 28px。扩展形态高 60px、圆角 18px（大号 72px、圆角 21px），左侧图标、右侧文字。
- 每屏只放一个 Fab。它和普通 `Button` 的区别：Fab 固定悬浮、只用于最主要的那个操作。
- 与 `Toolbar` 并排时两者等高。

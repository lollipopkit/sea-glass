# SegmentedNav

在 2 到 4 个同级视图之间切换的胶囊导航栏。

- 使用方提供：`items`（`{id, label, icon?}`）、`aria-label`；受控时传 `value` 与 `onChange`，非受控时可传 `defaultValue`。
- 外沿到选项的内边距为 5px；选项高度 38px，左右内边距 `space-4`；导航栏总高 48px。选项文字 15/20、字重 500，比其他胶囊控件小一级，使文字与导航栏高度的比例与参考设计一致。
- 大号 `size="lg"`：导航栏总高 66px，内边距 8px，选项高 50px、左右内边距 20px，文字 20/26，图标 26px（按参考图测量）。用于屏幕底部的应用级切换。
- 选中项显示为内嵌的半透明 `*-hi` 高亮胶囊（50%，透出导航栏的颜色和颗粒），并在标签前显示其图标（默认实心，`filled={false}` 改为线性）；未选中项只显示文字。
- 切换动画：选中高亮是一个独立的胶囊，在选项之间滑动。胶囊的左右两边分别由弹簧驱动：移动方向前方的一边刚度高（k=560），后方的一边刚度低（k=230），所以胶囊先向新选项拉长、再收拢，拉长时高度最多压扁 10%，约 0.3 秒停稳，末尾有轻微回弹。图标在新选项上同时展开（宽度、间距、不透明度、缩放一起过渡约 0.38 秒），在原选项上同时收起，文字随之平移，不发生跳动。胶囊每一帧读取目标选项的位置，图标展开引起的宽度变化也会被跟随。按下已选中的选项时，胶囊与选项一起按压形变。系统开启“减少动态效果”时直接切换。
- 默认 `tone` 为 `lilac`。一个页面只放一个 SegmentedNav。
- 支持左右方向键切换；选中项是唯一可通过 Tab 键聚焦的项。
- 标签使用单个名词，不超过 12 个字符；超过 4 项时改用列表或菜单。
